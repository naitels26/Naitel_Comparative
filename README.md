# Naitel_Comparative
Las respuestas nuevas incorporan `facilidad` y `claridad`, también incluidas en CSV. Las anteriores se conservan y muestran esos campos vacíos al exportar. SQLite agrega las columnas automáticamente; MongoDB no requiere una migración de documentos. Para las nuevas participaciones son obligatorias las respuestas A o B de facilidad y claridad. Los registros anteriores se conservan sin alterar, incluidas las antiguas respuestas neutrales.
