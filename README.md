# Naitel_Comparative
Las respuestas nuevas incorporan `facilidad` y `claridad`, también incluidas en CSV. Las anteriores se conservan y muestran esos campos vacíos al exportar. SQLite agrega las columnas automáticamente; MongoDB no requiere una migración de documentos. Para las nuevas participaciones son obligatorias las respuestas A o B de facilidad y claridad. Los registros anteriores se conservan sin alterar, incluidas las antiguas respuestas neutrales.

## Navegación móvil

En ambas versiones, desliza a izquierda o derecha sobre el contenido de una diapositiva para avanzar o retroceder. El scroll vertical, los formularios, enlaces, menús y controles conservan su interacción normal. El gesto también permite pasar de la primera a la última diapositiva.

La tira de marcas de B espera a tener un ancho visible antes de formar su bucle. Se reconstruye al cambiar de tamaño y evita la pausa persistente por hover en pantallas táctiles. Pausa el movimiento cuando B está oculta o la encuesta está abierta y respeta la preferencia de movimiento reducido. Los ajustes viven en el comparador; no se editaron las referencias.
